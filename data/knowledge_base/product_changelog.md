# Product Changelog / Release Notes

*Document type: guide | Product line: AquaPearl 500 Pro | Last updated: 2026-01-30*

## Firmware 2.4 (Released 2026-01-15)

- Changed the meaning of alert code E-05. Previously, E-05 indicated a Wi-Fi connectivity fault. As of firmware 2.4, E-05 now indicates the RO membrane needs replacement. Units running firmware older than 2.4 will still show the old meaning for E-05.
- Improved filter-life prediction accuracy in the mobile app.
- Fixed an issue where the app would occasionally fail to sync alert history after a power outage.

## Firmware 2.3 (Released 2025-11-02)

- Added support for Bluetooth pairing without requiring the unit to be in setup mode.
- Minor bug fixes to the flow-rate sensor calibration.

## Firmware 2.2 (Released 2025-08-20)

- Initial release of water-usage telemetry reporting to the mobile app.
- Added E-08 (TDS sensor out of range) as a new alert code.

## How to Check Your Firmware Version

Open the Pearlz app, go to Device Settings, and the firmware version is shown under "Device Info." If your unit shows firmware 2.3 or older, alert code E-05 refers to a Wi-Fi fault, not a membrane replacement — update your firmware or check with support if you see this code.
